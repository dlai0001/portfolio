# Project images

Drop project art here. File names are matched by project slug:

- Card image:        `<slug>.png`            (e.g. `mealiq.png`)
- Architecture image: `<slug>-architecture.png` (e.g. `mealiq-architecture.png`)

Current slugs: `mealiq`, `az-104-study-guide`.

Recommended card image size: ~800x320 (any aspect works; it's cropped to cover).
Missing images degrade gracefully — cards show a gradient banner, diagrams are hidden.
